## 5. 边界与异常

### 5.1 边界情况

| 场景 | 预期行为 |
|------|---------|
| 输入为空字符串 | 返回 400，提示"输入不能为空" |
| 输入超长（> 10000 字符） | 截断至 10000 字符并继续处理 |
| 并发请求同一资源 | 通过分布式锁排队处理 |
| 外部服务超时 | 返回 504，提示"服务暂时不可用" |
| Redis 不可用 | 降级到本地缓存或跳过缓存 |

### 5.2 异常处理

```typescript
// 后端异常处理示例
try {
  const result = await this.externalService.call(params);
  return result;
} catch (error) {
  logger.error('外部服务调用失败', {
    module: 'XxxService',
    error: error.message,
    params: sanitizeParams(params), // 注意：不能记录敏感字段
  });
  throw new InternalServerErrorException('服务暂时不可用，请稍后重试');
}
```
